Everyday Morocco. Unexpected stories.

A project for creating original, short vertical comedy in Moroccan Darija: an overconfident teapot, a café chair asking for a day off, or a sandwich acting like a football coach. Ideas focus on playful fictional situations, without targeting communities or copying creators.

The planned workflow uses Gemini for concepts and narration, Kling's official API for video generation, and n8n for scheduling. TikTok integration is in development and subject to approval. This is currently a single-channel creator project, not an approved public posting service.

Videos must be reviewed before sharing. Any future TikTok integration will use official OAuth and Content Posting APIs with approved permissions. We never ask for TikTok passwords. We make no promises of views, followers, or income.

Privacy Policy

Published October 10, 2026 · Current development-stage policy

This public website

This informational website has no registration, payment forms, analytics scripts, tracking pixels, or credential collection. It is hosted by GitHub Pages. GitHub may process technical request information, such as IP addresses and browser details, according to GitHub's privacy statement.

Creative workflow

The intended private workflow sends fictional prompts and scripts to Google Gemini and Kling to generate creative material. Do not include personal information, private images, or confidential material in prompts. Those providers apply their own service and data policies. Generated content and operational records are held in the operator's private automation environment; they are not published to this website.

TikTok connection

TikTok account connection is not offered on this website. If enabled after approval, OAuth will request only the permissions approved for the app and selected by the account owner. Access and refresh tokens must be stored securely on the private backend, never in this website or a public repository. Media will be sent to TikTok only with the creator's consent. Public posting additionally requires explicit approval for each individual post.

Control, retention, and deletion

The project does not sell account data or use it for advertising. Before account connection is enabled, the operator will publish a private contact method, an operational retention schedule, and procedures for access and deletion requests. Users can revoke any future TikTok connection through TikTok's app permissions settings. Disconnecting an integration does not automatically delete content already shared on TikTok.

Policy updates

This policy will be updated before the service begins collecting account information or changes its data practices. The current site is informational; no service launch or TikTok approval is implied.
