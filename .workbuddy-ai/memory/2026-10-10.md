## Key facts to remember

- n8n Merge node returns NOTHING when one input is empty — never use it to
  rejoin two mutually exclusive branches. Wire both branches directly instead.
- n8n workflow JSON needs a top-level `id` or the CLI importer fails with
  `NOT NULL constraint failed: workflow_entity.id`.
- The user's n8n runs at http://localhost:5678; `/rest/workflows` returns 401
  without an n8n API key.
- Kling text-to-video caps at 5s/10s and produces no audio — the "20-35s with
  Darija voiceover" target needs multi-clip ffmpeg stitch + TTS, not wired.
