Brainrot Maroc Video Creator

An automation tool that drafts one original, vertical comedy short per day in Moroccan Darija, renders it with an AI video model, and delivers it to TikTok only through TikTok’s official Content Posting API.

Short description (app store style)

Brainrot Maroc Video Creator helps a Moroccan TikTok creator publish consistently. Every day it writes one original short-form comedy concept set in everyday Moroccan life, turns it into a 9:16 vertical video with an AI video model, writes a Darija voiceover script and a short caption, runs an automated safety check, and sends the finished video to the creator’s TikTok account using TikTok’s official Content Posting API.

What it does

  • Generates one original daily concept: setting, hook, visual prompt, Darija voiceover script, caption and hashtags.
  • Produces 9:16 vertical video clips with an AI text-to-video model.
  • Runs an automated policy and safety check before anything is sent anywhere.
  • Delivers the result to TikTok through TikTok’s official Content Posting API — by default as a draft in the creator’s TikTok inbox, not as a public post.
  • Asks for explicit human confirmation before any public post.

What it does not do

  • It does not guarantee views, likes, followers or income. No tool can.
  • It does not copy other creators, use copyrighted characters, music or brands, or impersonate real people.
  • It never asks for or stores your TikTok password. Access is granted with TikTok OAuth (Login Kit) and can be revoked at any time.
  • It does not publish publicly without your confirmation.

How access works

Connecting the tool to TikTok uses TikTok’s official OAuth flow. You log in on TikTok’s own page and approve the requested scopes. The tool receives an access token that is stored only in the operator’s own automation server. You can revoke access at any time from your TikTok account settings.

Content standards

Concepts are generated under a fixed written policy: everyday Moroccan settings, absurd escalation, fast pacing, fictional generic characters. Content that involves hate speech, sexual content, violence, dangerous stunts, self-harm, drugs, politics, religion, real-person impersonation or copyrighted material is rejected by the automated check and is not sent onward.
